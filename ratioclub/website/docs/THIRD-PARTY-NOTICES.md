# Third-party notices

Runtime library notices for React, React DOM, Scheduler, GSAP and the GSAP React integration are retained in `third-party-licenses/` where supplied by those packages. Local font licenses remain alongside source fonts and are emitted in the static build. Keep those notices with redistribution.

Dependency package names, versions, registry sources, integrity hashes and license identifiers are in the website and optional editor lockfiles. Dependencies installed later carry their own licenses. Brand imagery/media are delivered as supplied for this implementation; confirm project redistribution/usage rights with the content owner. No personal authorship or account history has been added to this package.
